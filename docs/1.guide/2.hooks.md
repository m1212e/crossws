# Hooks

> Using hooks, you can define a WebSocket server that works across runtimes with the same syntax.

Crossws provides a cross-platform API to define WebSocket servers. An implementation with these hooks works across runtimes without needing you to go into details of each of them. You only define the life-cycle hooks that you only need.

> [!TIP]
> Using `defineHooks()` wrapper is optional and for type support and code auto completion.

```ts
import { defineHooks } from "crossws";

const hooks = defineHooks({
  upgrade(req) {
    console.log(`[ws] upgrading ${req.url}...`)
    return {
      headers: {}
    }
  },

  open(peer) {
    console.log(`[ws] open: ${peer}`);
  },

  message(peer, message) {
    console.log("[ws] message", peer, message);
    if (message.text().includes("ping")) {
      peer.send("pong");
    }
  },

  close(peer, event) {
    console.log("[ws] close", peer, event);
  },

  error(peer, error) {
    console.log("[ws] error", peer, error);
  },
});
```

# Event description
## upgrade
This hook is called when an HTTP request is received that is attempting to upgrade to a WebSocket connection. It's the first hook triggered in the WebSocket handshake process. It allows you to inspect the incoming HTTP request to perform checks like authentication, authorization or other pre-connection checks. You can return a Response object which will be sent to the client to .e.g. set headers in the upgrade request.

## open
This hook is called immediately after the WebSocket connection is successfully established. It indicates that the WebSocket handshake is complete, and the connection is ready for usage. You can use this to e.g. store away the peer for later use, sending  an initial message or log the new connection.

## message
This hook is called whenever a message is received from the connected client. You can use this to process the message somehow and to respond to the peer which the message has been sent from.

## close
This hook is called when the WebSocket connection is closed, either by the client or the server. It allows you to react to close events by e.g. removing the peer reference from a list of active connections or to log the event.

## error
This hook is called when an error occurs during the WebSocket connection. You can use it to react to failures in an appropriate way by e.g. logging the event or by closing the connection.
